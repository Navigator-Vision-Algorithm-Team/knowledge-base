浙江大学 HelloWorld 战队轮腿哨兵导航算法

项目概览

项目 内容
仓库 Polyacetone/HWSentryNav26
定位 基于 GLIM 定制的因子图滑窗里程计
规划 空间 A、Kinodynamic A、MINCO 和速度剖面优化
控制 LPV 隐状态模型与自研 FDDP 模型预测控制
环境 Ubuntu 24.04 LTS、ROS 2 Jazzy
许可证 MIT License

HWSentryNav26 是浙江大学 HelloWorld 战队面向 RoboMaster 2026 轮腿哨兵机器人的 ROS 2 导航框架。项目针对轮腿底盘受到强烈碰撞、翻车、跨台阶和坡道等工况进行了定制，也可以在修改机器人模型和约束后为其他构型的哨兵提供参考。

主要技术亮点

1. 因子图优化里程计

项目在 GLIM 基础上进行定制，使用固定滞后因子图在滑动窗口内联合优化历史位姿。相较只依赖相邻帧递推的方案，该结构有助于缓解剧烈碰撞和短时异常观测对当前位姿的影响。

需要注意，这里的“鲁棒性较好”来自项目设计目标和战队实车经验，并不意味着在所有雷达安装方式、底盘振动和场地结构下都不会失效。

2. 跨地形路径规划

规划链路采用从粗到细的分阶段策略：

空间 A* 选择地形通道
        │
        ▼
提取安全走廊
        │
        ▼
Kinodynamic A* 动力学搜索
        │
        ▼
MINCO 分段五次多项式连续优化
        │
        ▼
台阶执行约束与弧长域速度剖面优化

空间 A 负责决定整体通道，Kinodynamic A 使用曲率—弧长运动基元寻找动力学可行路径，随后通过 MINCO 和速度剖面优化获得可供底盘跟踪的轨迹。

3. LPV 隐状态模型与 FDDP MPC

项目使用实车记录的命令—响应数据离线辨识 LPV 模型，并以底盘高度作为调度变量。不可直接测量的内部状态由在线观测器估计，管式辅助环用于抑制模型误差，MPC 求解器采用自主实现的 FDDP。

这部分与具体轮腿底盘动力学、采样周期、执行器延迟和辨识数据关系密切。迁移到其他底盘时，需要重新采集数据、辨识模型和调节代价权重，不能直接复用原车参数。

4. 扁平化导航状态机

项目没有采用 Navigation2 行为树作为任务管理主体，而是设计了扁平化有限状态机。该设计便于按比赛逻辑直接增加和维护状态，但也意味着任务恢复、异常处理和生命周期管理需要由项目自身负责。

5. 动态障碍物预测与避让

动态障碍物链路包含：

  1. 点云差分提取动态点；
  2. 形态学闭运算和连通域聚类；
  3. 匈牙利匹配完成帧间关联；
  4. 卡尔曼恒速滤波维护航迹；
  5. 按衰减速度模型进行多步外推；
  6. 将逐帧预测代价图按时间对齐送入 MPC。

该方案不仅依据障碍物当前位置避让，还会利用预测位置影响后续控制时域内的代价。

6. 离线建图优化与动态物体去除

在线里程计使用固定滞后平滑以满足实时性，离线阶段则将保存的关键帧组织为两级因子图：局部子图内进行帧间 VGICP 优化，全局再以子图为节点进行 VGICP 和回环优化。获得全局一致轨迹后，使用 3D-DDA 光线投射清理动态物体并输出全局点云地图。

这种流程适合在适应性训练中先保存原始关键帧，再离线生成精度更高、动态残影更少的地图。

环境与构建入口

项目推荐 Ubuntu 24.04 LTS 和 ROS 2 Jazzy，核心依赖包括 Eigen3、OpenCV、PCL、Asio、Boost、MsgPack、GTSAM 和 gtsam_points。构建时还需要同一组织下的公共消息与工具仓库 HWSentryCommon26。

mkdir ~/hwsentry_ws && cd ~/hwsentry_ws
git clone https://github.com/Polyacetone/HWSentryCommon26
git clone https://github.com/Polyacetone/HWSentryNav26
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release

部署前建议依次阅读：

  • README：环境与依赖
  • DESIGN：架构设计

  • DEMO：离线演示
  • DEPLOY：实车部署

实车表现与适用边界

据开源者说明，项目在临港测试中实现过跨越单级/二级台阶、上高地、飞坡和反向飞坡，但部分动作的稳定性仍有提升空间。这些结果来自特定机械结构、控制器和场地条件，尚不能直接推导为其他机器人上的性能保证。

迁移时至少需要重新确认：

  • 轮腿底盘几何和动力学模型；
  • 底盘高度、速度和加速度约束；
  • LiDAR/IMU 外参与时间同步；
  • 地形语义、台阶执行契约和安全走廊宽度；
  • LPV 辨识数据、观测器和 MPC 权重；
  • 状态机中的比赛任务与故障恢复逻辑。
