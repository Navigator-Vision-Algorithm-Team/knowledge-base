# Navigator 视觉与导航组知识库

本仓库用于教学与在开发项目文档，修改内容请对main分支的docs目录提交pull requests.

导航组大一新人从[导航学习入口](docs/navigation/README.md)开始，查看[最终培训路线](docs/navigation/onboarding/learning-route.md)、[实际系统地图](docs/navigation/system/README.md)和[实践考核](docs/navigation/assignments/README.md)。内容对齐 Navigation-2027；源码审查与实车验证状态分别标注。

具体学习按[16 周任务单](docs/navigation/onboarding/weekly-plan.md)推进；补充[带参考解答的源码练习](docs/navigation/assignments/reading-labs.md)及[自学材料与进阶项目](docs/navigation/self-study/README.md)，包含基础编程、数学定位、规划控制、ROS2 系统的指定章节与实验。
