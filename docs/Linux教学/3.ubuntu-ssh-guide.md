# Ubuntu SSH 教程（安装、使用与排错）

本文面向 Ubuntu，覆盖从下载安装开始，到常见使用、跨网访问、连通性测试、文件传输与故障排查。

## 1) 安装 OpenSSH（从下载开始）

### 1.1 安装服务端（被连接的电脑）
```bash
sudo apt update
sudo apt install -y openssh-server
```

### 1.2 安装客户端（发起连接的电脑）
多数 Ubuntu 默认自带客户端，如缺失可安装：
```bash
sudo apt install -y openssh-client
```

### 1.3 启动并设置开机自启
```bash
sudo systemctl enable --now ssh
sudo systemctl status ssh
```

### 1.4 确认端口在监听
```bash
sudo ss -tulpn | grep ssh
```
常见情况下会看到 `sshd` 监听在 22 端口（或自定义端口）。

### 常见问题与处理
- **`Unit ssh.service could not be found`**：装的是客户端不是服务端，重新安装 `openssh-server`。
- **服务未运行**：执行 `sudo systemctl restart ssh`，查看日志：`sudo journalctl -u ssh -n 100`。
- **端口被占用**：用 `sudo lsof -i :22` 查占用进程，必要时在 `/etc/ssh/sshd_config` 改端口并重启。

## 2) 查看 Ubuntu 的 IP 地址

### 2.1 局域网 IP
```bash
ip a
```
找到活动网卡（如 `eth0`/`wlan0`）下面的 `inet` 地址。

### 2.2 快速查看
```bash
hostname -I
```

### 2.3 公网 IP（需要跨网连接时）
```bash
curl -s https://ifconfig.me
```

### 常见问题与处理
- **没有 IP**：网卡未启用，执行 `ip link` 查看，必要时 `sudo ip link set <iface> up`。
- **IP 不对**：同时连了 Wi-Fi 和有线时，选择正在使用的网卡地址。

## 3) 连接别人的电脑（SSH 基本用法）

### 3.1 基本连接
```bash
ssh <用户名>@<IP或主机名>
```
示例：
```bash
ssh alice@192.168.1.50
```

### 3.2 指定端口
```bash
ssh -p 2222 alice@192.168.1.50
```

### 3.3 指定密钥文件
```bash
ssh -i ~/.ssh/id_ed25519 alice@192.168.1.50
```

### 3.4 远程执行单条命令
```bash
ssh alice@192.168.1.50 "uname -a"
```

### 3.5 调试连接问题（详细输出）
```bash
ssh -vvv alice@192.168.1.50
```

### 常见问题与处理
- **首次连接提示主机指纹**：看到
  ```
  The authenticity of host '...' can't be established.
  ```
  确认是可信主机后输入 `yes`。
- **用户名错误**：确认目标机上存在该用户，可在目标机上执行 `whoami` 或 `id`。
- **主机名解析失败**：看到 `Could not resolve hostname`，改用 IP 或修正 DNS/hosts。

## 4) 密钥登录

### 4.1 生成密钥
```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```
一路回车使用默认路径：`~/.ssh/id_ed25519`。

### 4.2 复制公钥到目标机
```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub alice@192.168.1.50
```

### 4.3 手动写入公钥
```bash
cat ~/.ssh/id_ed25519.pub | ssh alice@192.168.1.50 "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
```

### 4.4 权限要求
```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
chmod 600 ~/.ssh/id_ed25519
```

### 常见问题与处理
- **`ssh-copy-id: command not found`**：安装客户端包 `openssh-client`。
- **仍然要输入密码**：检查目标机 `~/.ssh/authorized_keys` 是否写入成功，权限是否正确。
- **`WARNING: UNPROTECTED PRIVATE KEY FILE!`**：私钥权限过宽，执行 `chmod 600 ~/.ssh/id_ed25519`。
- **`Bad owner or permissions`**：`.ssh` 目录或文件权限不对，按 4.4 修正。
- **`Too many authentication failures`**：加 `-o IdentitiesOnly=yes` 指定单一密钥。

## 5) 防火墙（UFW）

### 5.1 查看状态
```bash
sudo ufw status verbose
```

### 5.2 放行 SSH
```bash
sudo ufw allow ssh
sudo ufw enable
```

### 5.3 放行自定义端口
```bash
sudo ufw allow 2222/tcp
```

### 5.4 仅放行指定来源 IP（更安全）
```bash
sudo ufw allow from 192.168.1.10 to any port 22 proto tcp
```

### 常见问题与处理
- **能 ping 但连不上 SSH**：端口可能被防火墙拦截，检查并放行。
- **启用 UFW 后断连**：未放行 SSH，执行 `sudo ufw disable` 临时恢复，再按 5.2 放行。

## 6) 连通性与端口测试（排查核心）

### 6.1 `ping`（测试基本连通）
```bash
ping -c 4 192.168.1.50
```
注意：有些设备禁用 ICMP，ping 不通不代表 SSH 一定不通。

### 6.2 `traceroute`（查看链路）
```bash
sudo apt install -y traceroute
traceroute 192.168.1.50
```

### 6.3 `nc`（测试端口是否可达）
```bash
nc -vz 192.168.1.50 22
```

### 6.4 `telnet`（替代端口测试）
```bash
telnet 192.168.1.50 22
```

### 6.5 服务器侧确认端口监听
```bash
sudo ss -tulpn | grep ssh
```

### 常见问题与处理
- **ping 通但端口不通**：SSH 服务未启动或端口被防火墙拦截。
- **ping 不通**：IP 错误、设备离线、跨网路由不可达。

## 7) 不在同一局域网时怎么连接

### 7.1 公网 IP + 路由器端口转发
- 路由器将公网端口（如 2222）转发到内网主机的 22 端口。
- 客户端使用公网 IP 连接：`ssh -p 2222 user@公网IP`。

### 7.2 没有公网 IP（运营商内网/CGNAT）
- 这种情况下无法直接端口转发。
- 可使用 VPN 组网（如 Tailscale/ZeroTier）或使用云服务器中转。

### 7.3 VPN/代理导致的问题
- **VPN 改变路由**：用 `ip route` 检查默认路由是否指向 VPN。
- **连的是 VPN 分配的地址**：确保用的是 VPN 内的地址，而不是本地局域网地址。

## 8) 常见报错与处理（集中说明）

### 8.1 `Connection refused`
- 服务器没开 SSH：`sudo systemctl status ssh`。
- 端口被防火墙阻断：`sudo ufw allow ssh`。
- 端口写错：加 `-p <端口>`。

### 8.2 `Connection timed out`
- 目标离线或跨网不可达。
- 路由器或 ISP 屏蔽端口。

### 8.3 `No route to host`
- IP 错误或跨网无路由。
- 不同网段且无网关/路由配置。

### 8.4 `Permission denied (publickey,password)`
- 用户名/密码错误。
- 公钥未写入或权限错误。
- `sshd_config` 中禁用了密码或公钥登录。

### 8.5 `Host key verification failed`
- 目标主机指纹变化，清理旧记录：
```bash
ssh-keygen -R 192.168.1.50
```

### 8.6 `REMOTE HOST IDENTIFICATION HAS CHANGED!`
- 可能重装或 IP 被其他设备占用，确认后更新 `known_hosts`。

### 8.7 `kex_exchange_identification: read: Connection reset by peer`
- 服务端主动断开（防爆破、连接过多、资源不足）。
- 查看服务端日志：`sudo journalctl -u ssh -n 200`。

### 8.8 `WARNING: UNPROTECTED PRIVATE KEY FILE!`
- 私钥权限过宽：`chmod 600 ~/.ssh/id_ed25519`。

### 8.9 `Could not resolve hostname`
- 主机名拼错或 DNS 不可用，改用 IP。

## 9) SSH 配置文件

### 9.1 客户端配置（`~/.ssh/config`）
```text
Host myserver
  HostName 192.168.1.50
  User alice
  Port 22
  IdentityFile ~/.ssh/id_ed25519
```
使用别名连接：
```bash
ssh myserver
```

### 9.2 服务端配置（`/etc/ssh/sshd_config`）
常见配置：
- `Port 2222`
- `PasswordAuthentication no`（密钥可用后再关闭密码）
- `PermitRootLogin no`

修改后重启：
```bash
sudo systemctl restart ssh
```

## 10) SSH 下的文件传输工具

### 10.1 `scp`（简单复制）
**用法**
```bash
scp file.txt alice@192.168.1.50:/home/alice/
scp -r folder/ alice@192.168.1.50:/home/alice/
scp alice@192.168.1.50:/home/alice/file.txt ./
```
**常见问题**
- 权限不足：检查目标目录权限。
- 连接超时：同 SSH 排查 IP/端口/防火墙。
- 速度慢：加 `-C` 开启压缩。

### 10.2 `sftp`（交互式传输）
**用法**
```bash
sftp alice@192.168.1.50
```
常用命令：`ls`、`cd`、`pwd`、`get`、`put`、`mkdir`。

**常见问题**
- 连接不上：同 SSH 排查。
- `Permission denied`：目标目录权限不足。

去[菜鸟教程](https://www.runoob.com/linux/linux-comm-sftp.html)，上面更加的详细喵

### 10.3 `sshfs`（把远端目录挂载为本地目录）
**用法**
```bash
sudo apt install -y sshfs
mkdir -p ~/mnt/remote
sshfs alice@192.168.1.50:/home/alice ~/mnt/remote
```
卸载：
```bash
fusermount -u ~/mnt/remote
```
**常见问题**
- 提示权限不足：确保本地目录可写、远端目录有权限。
- 断线后卡住：先卸载再重新挂载。
