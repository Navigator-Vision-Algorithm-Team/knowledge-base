# 华东理工大学起源战队：哨兵机器人建图与地图编辑工具合集

> 本页收录华东理工大学起源战队开源的两项哨兵机器人地图工具，分别用于动态物体滤除和地图人工编辑。项目仍可能持续更新，具体安装步骤和参数请以对应仓库的最新 README 为准。
>
> 资料核对时间：2026 年 8 月 18 日。

## 项目概览

| 项目 | 主要用途 | 运行环境 | 项目地址 |
|---|---|---|---|
| ERASOR2 二次开发版 | 从离线 LiDAR 序列中滤除人、车等动态物体，生成更干净的静态点云地图 | Ubuntu 20.04/22.04；无需 ROS/ROS 2 | [Tony-tpc/ERASOR2](https://github.com/Tony-tpc/ERASOR2) |
| ROS2 Map Edit Plugin | 在 RViz 中编辑二维栅格地图，并标注多边形语义区域 | ROS 2、RViz 2 | [Tony-tpc/map_edit](https://github.com/Tony-tpc/map_edit) |

两项工具解决的是不同阶段的问题：ERASOR2 主要处理三维点云中的动态物体残影，`map_edit` 主要修改供导航使用的二维栅格地图及区域信息。

## 1. 动态物体滤除建图工具：ERASOR2

### 项目背景

在适应性训练和自由调试阶段，场地内的人、车等动态障碍物容易被累计进点云地图，形成残影、拖影或错误障碍。人工逐点修改点云耗时较长，因此起源战队在 [url-kaist/ERASOR2](https://github.com/url-kaist/ERASOR2) 的基础上进行了二次开发，使其更适合处理自采 LiDAR 序列。

### 处理流程

```text
逐帧点云 + LiDAR 位姿
        │
        ├── Patchwork++：地面分割
        ├── HDBSCAN：实例聚类
        ├── mapgen：生成原始累计地图
        └── ERASOR2：检测并去除动态物体
                    ├── 静态点云地图
                    └── 逐帧 MOS 标签
```

### 主要特点

- 使用纯 CMake/C++17 构建，不依赖 ROS master、catkin 或 ROS 2 工作空间。
- 直接读取 YAML 参数文件，并支持 KITTI 3×4 矩阵和“时间戳 + 平移 + 四元数”两种位姿格式。
- 提供 `scripts/run_sequence.sh` 一键脚本，可完成输入检查、编译、标签预处理、原始地图生成和动态物体滤除。
- 支持长序列 external-memory streaming，通过地图压缩和时间窗口降低峰值内存占用。
- 默认可在无桌面的服务器上运行；需要可视化时可以选择启用 Rerun。
- 输出静态 PCD 地图和逐帧 MOS 标签，便于后续检查或接入其他建图流程。

### 推荐入口

准备好符合仓库要求的 sequence 目录和参数文件后，可使用：

```bash
./scripts/run_sequence.sh \
  /data/sequences/00 \
  config/erasor2/seq_00.yaml
```

完整依赖、数据格式、参数说明和常见问题请阅读项目的 [README](https://github.com/Tony-tpc/ERASOR2#readme) 和 [USAGE.md](https://github.com/Tony-tpc/ERASOR2/blob/main/USAGE.md)。

### 使用前注意

1. 位姿必须表示直接的 `T_map_lidar`。如果输入的是相机位姿、反向变换或其他传感器位姿，需要先完成外参转换。
2. 点云、位姿和标签必须按帧严格对应，并使用相同的时间基准和 LiDAR 坐标系。
3. Patchwork++ 地面分割和 HDBSCAN 实例聚类的质量会直接影响最终滤除效果。
4. 自采数据缺少语义真值时可以使用 dummy label 运行，但由此得到的 Preservation、Rejection 和 F1 指标不能作为可信的算法性能结论。
5. 阈值需要根据雷达线数、安装高度、点密度和场地尺度重新调整，不建议直接把示例参数当作所有设备的最优参数。

## 2. 地图编辑工具：ROS2 Map Edit Plugin

### 项目简介

`map_edit` 是一个 ROS 2 RViz 插件，参考了 [ros_map_edit](https://gitee.com/reinovo/ros_map_edit) 并进行了 ROS 2 兼容和功能扩展。它可以结合 RViz 中的地图、点云和导航效果，对二维占据栅格地图进行可视化编辑。

### 主要特点

- 可以打开本地地图 YAML，也可以订阅 `/map` 话题加载正在使用的地图。
- 提供黑白橡皮擦：左键绘制黑色障碍，右键绘制白色可通行区域。
- 支持笔刷大小调整、直线绘制、多步撤销和重做。
- 可将结果保存为 `.pgm + .yaml`，供导航系统重新加载。
- 提供 `RegionTool` 多边形区域工具，可用于标注禁行区、感兴趣区等语义区域。
- 支持区域 YAML 的导入、导出、清空和多区域管理，也可以保存自定义属性。

### 编译与运行

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src
git clone https://github.com/Tony-tpc/map_edit
cd ..

rosdepc install -r --from-paths src --ignore-src --rosdistro "$ROS_DISTRO" -y
colcon build --symlink-install
. install/setup.bash
ros2 launch map_edit map_edit.launch.py
```

详细操作方法和演示截图见项目 [README](https://github.com/Tony-tpc/map_edit#readme)，也可以观看作者提供的 [演示视频](https://www.bilibili.com/video/BV1XPtJzbEn8)。

### 使用前注意

1. 插件修改后的地图发布在 `/map_edit` 话题，不会立即改变导航系统正在使用的地图。
2. 若要让修改生效，需要先保存 PGM/YAML，再让导航节点重新加载地图。
3. 区域多边形至少需要三个顶点；导出的坐标与地图使用同一坐标系。
4. 地图修改前建议备份原始 PGM、YAML 和区域文件，避免误操作覆盖可用地图。

## 3. 两项工具如何配合

可以按以下思路将两项工具接入哨兵地图制作流程：

```text
自采 LiDAR 点云与位姿
        │
        ▼
ERASOR2 动态物体滤除
        │
        ▼
干净的三维静态点云地图（PCD）
        │
        ▼
团队已有的二维栅格地图生成/转换流程
        │
        ▼
map_edit 人工修图与语义区域标注
        │
        ├── 导航地图：PGM + YAML
        └── 区域信息：YAML
```

需要特别注意：**ERASOR2 输出的是三维 PCD 点云地图，`map_edit` 编辑的是二维 PGM/YAML 占据栅格地图，两者不能直接无缝衔接。** 中间仍需要使用团队现有的点云投影、栅格化或导航地图生成流程。

## 4. 选型建议

| 遇到的问题 | 推荐工具 |
|---|---|
| 点云地图中存在人、车等动态物体残影 | ERASOR2 |
| 长序列处理时内存占用过高 | ERASOR2 streaming 模式 |
| 二维导航地图存在少量错误障碍或缺口 | `map_edit` |
| 需要绘制禁行区、限速区或感兴趣区 | `map_edit` 的 `RegionTool` |
| 希望得到较完整的最终地图 | 先用 ERASOR2 自动滤除，再转换为二维地图并用 `map_edit` 检查 |
